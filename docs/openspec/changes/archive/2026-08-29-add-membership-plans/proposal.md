# Proposal: add-membership-plans

## Why

当前变现只有 ¥9.9/20 积分的一次性尝鲜包：重度用户折合单张价没有任何优惠，只能反复小额购买，产品缺少可持续的收入形态。转会员卡订阅制（手动续费形态——聚合支付通道不支持自动代扣），为重度用户提供约 3–4 折单张价的价值阶梯，形成周期性收入。底层计费保持"一张图一分"不变；免费层维持注册送 5 张一次性体验积分现状（单号白嫖收益约 ¥0.21，远低于谷歌账号注册摩擦，刷号无利可图）。

## What Changes

- 新增会员卡 SKU（服务端定价单一来源）：标准月卡 ¥19.9（100 张/期）、标准年卡 ¥199（12 期 × 100 张）、Pro 月卡 ¥49.9（300 张/期）、Pro 年卡 ¥499（12 期 × 300 张）。
- 双池积分模型：新增"订阅池"（有到期时间，按周期发放、不滚存、到期清零）；现有余额与积分包充值归入"永久池"。扣费顺序先订阅池、后永久池；每张成功生成扣 1 分的原子扣费点不变。
- 会员周期惰性引擎：购买立即发放首期；年卡剩余 11 期按 30 天间隔在读路径惰性发放；过期订阅池读时清零。不引入 cron，与现有"无定时任务对账"的哲学一致。
- "叠加顺延"购买语义：有效期内再次购买（续费/升级/降级统一处理）= 立即发放一期 + `paid_until` 顺延一个周期 + 后续期按新档发放；不按比例折算、不退差价。
- 订单体系扩展：`orders` 增加 `kind`（pack|plan）与会员快照；webhook/对账/手工补发沿用现有验签、金额核对与幂等机制，发货按 kind 分支。
- `/upgrade` 改版为定价页：免费/标准/Pro 三栏 + 月/年切换（年付省约 17%），积分包保留为所有人可买的"加购"区。
- 会员状态展示：积分徽章拆分订阅池（含到期日）与永久池；到期前 3 天站内提醒续费。
- `credit_events` 新增会员期发放/到期清零流水类型。

**Non-goals**(本期不做):自动续费/代扣（通道资质不支持，未来开通官方周期扣款再评估）、订阅积分滚存、按比例折算与退款、多会员并存、邀请/返利、免费层任何改动。

## Capabilities

### New Capabilities

- `membership`: 会员卡目录与定价、购买与激活、"叠加顺延"续费/换档语义、订阅池周期发放与到期、双池扣费顺序、定价页与会员状态展示、到期提醒。

### Modified Capabilities

- `billing`: 订单创建与快照规则泛化到会员卡商品（kind=plan）；积分入账与审计按订单类型分支发货——积分包入永久池，会员卡开通/顺延会员并发放当期积分；二者均保持原子与幂等。

## Impact

- **数据库**：新增迁移——`memberships` 表（plan_id、paid_until、next_grant_at、pending_tranches FIFO 队列）及 RLS；`profiles` 增加 `sub_credits`、`sub_credits_expires_at`；`orders` 增加 `kind` 与 `plan_snapshot`；`fulfill_order` 按 kind 分支；扣费 RPC 调整双池消耗顺序；余额预检查 RPC 化以承载惰性周期引擎。
- **新代码**：`lib/billing/plans.ts`（会员目录）、checkout/webhook/对账的 plan 分支、`/upgrade` 定价页改版、积分徽章双池展示、到期提醒条。无新增外部依赖。
- **既有行为**：一图一分扣费点不变（仅消耗顺序变化，覆盖经典/Agent/参考图全部路径）；免费层不变；存量用户余额自然成为永久池，零迁移。
- **测试**：会员目录与叠加顺延/周期发放的单元测试；webhook 分支与幂等测试；e2e（mock 通道）购买月卡 → 生成消耗订阅池 → 续费顺延 → 过期清零全链路。
- **风险**：订阅池过期时点与年卡末期和 `paid_until` 的对齐边界需重点测试；惰性发放必须幂等，防止并发读导致重复发放。
