## Why

当前付费模式中积分包（¥9.9/20 张）与会员卡并存，付费点分散；且免费用户与付费用户在产品能力上没有差异，Agent 对话这一核心差异化功能对所有用户开放，缺乏付费拉力。本次调整将会员卡确立为唯一充值通道，并以 Agent 对话作为会员专属能力，形成清晰的免费/付费分层。

## What Changes

- **BREAKING** 移除积分包购买：定价页删除积分包加购区，下单入口收口到会员卡；积分包商品目录下架
- 免费层定位为一次性试用：注册赠送 5 张积分（现状保持），用完即止，仅可使用经典生成模式；Agent 对话为会员专属
- `/generate` 页对免费用户展示 Agent 入口卡片（带会员专属锁标），点击后弹出升级引导而非进入 Agent 模式
- Agent 会话/消息服务端接口增加会员身份校验，非会员返回 403 与明确错误码；会员到期后下一轮请求即被拦截，历史对话与画布保留只读
- 定价页免费栏文案更新为「5 张试用积分 · 经典模式」，明示 Agent 为会员专属
- 余额不足（402）的购买引导全部指向会员卡
- 存量积分包用户永久池余额继续可用、不过期，仅不可再购

## Capabilities

### New Capabilities

（无）

### Modified Capabilities

- `billing`: 删除「积分包目录与服务端定价」需求及积分包发货支路；订单商品类型仅保留会员卡；余额不足引导指向会员卡
- `membership`: 定价页需求移除积分包加购区场景、免费栏改为差异化表述；新增「免费层能力边界」需求（一次性 5 张试用、仅经典模式）
- `agent-workbench`: 双模式入口需求增加会员门控场景（锁标展示、服务端 403、到期中断只读行为）

## Impact

- **代码**：`lib/billing/packs.ts`（下架积分包目录）、`app/upgrade/page.tsx`（移除加购区、免费栏文案）、`lib/agent/`（服务端会员校验）、`/generate` 页 Agent 入口组件（锁标与升级引导）、余额不足引导组件
- **规格**：`openspec/specs/billing`、`openspec/specs/membership`、`openspec/specs/agent-workbench` 三份能力 spec 的需求增删
- **数据库**：无迁移——双池模型保留，存量永久池余额不动；积分包商品可仅从前端与目录配置层下架，历史积分包订单数据保留
- **兼容性**：历史积分包订单与流水保留可查；免费用户积分获取渠道收窄为注册赠送与管理员调整，属预期行为
