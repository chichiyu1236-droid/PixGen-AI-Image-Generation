## MODIFIED Requirements

### Requirement: 双模式入口与对照
`/generate` 页面 SHALL 同时提供「经典生成」与「Agent 对话」两种模式入口，并以用户状态对照表述（「我有大致想法」/「还没想好，聊聊看」）。Agent 对话 SHALL 为会员专属能力：非会员用户 SHALL 能看到 Agent 入口卡片，但卡片 SHALL 带会员专属锁标标识，点击后 SHALL 展示升级引导（含定价页入口）而非进入 Agent 模式。会员用户 SHALL 能在两种模式间随时切换，切换 SHALL NOT 丢失另一模式已产生的表单内容或对话/画布状态。经典模式的既有行为 SHALL 保持不变。Agent 会话与消息的服务端接口 SHALL 校验当前用户的会员状态，非会员的任何 Agent 会话请求 SHALL 被拒绝并返回明确的未授权错误码。会员期内产生的会话在会员到期后 SHALL 保留只读，MUST NOT 被删除。

#### Scenario: 首次进入默认经典模式
- **WHEN** 已登录用户访问 `/generate`
- **THEN** 页面默认展示经典生成表单，同时可见 Agent 对话模式的入口卡片

#### Scenario: 模式切换保留状态
- **WHEN** 会员用户在 Agent 模式已有对话与画布内容后切到经典模式，再切回 Agent 模式
- **THEN** 原有对话记录与画布作品保持完整，不重置

#### Scenario: 免费用户看到带锁标的入口
- **WHEN** 非会员用户访问 `/generate`
- **THEN** Agent 入口卡片可见且带会员专属锁标，页面默认仍为经典生成模式

#### Scenario: 免费用户点击入口被升级引导
- **WHEN** 非会员用户点击 Agent 入口卡片
- **THEN** 页面展示升级引导与定价页入口，MUST NOT 进入 Agent 对话模式

#### Scenario: 服务端拒绝非会员会话请求
- **WHEN** 非会员用户绕过前端直接调用 Agent 会话或消息接口
- **THEN** 系统返回明确的未授权错误码，不创建会话、不执行任何工具调用

#### Scenario: 会员到期后对话保留只读
- **WHEN** 会员期内的用户会员到期后再访问原 Agent 会话
- **THEN** 历史消息与画布作品完整展示，发起新一轮请求被拦截并提示续费

### Requirement: 积分计费与余额保护
Agent 模式下的每次图片生成与每次编辑 SHALL 各扣 1 积分（与经典模式一致），变体按个数累计。工具调用展示的积分消耗 SHALL 与实际扣减一致。余额不足时系统 SHALL 在执行前拦截并引导购买会员卡，MUST NOT 出现已扣减未产出或已产出未扣减的账实不符。

#### Scenario: 余额不足拦截
- **WHEN** 积分为 0 的用户在 Agent 模式发起生成
- **THEN** Agent 提示余额不足并给出购买会员卡入口，不调用生图工具

#### Scenario: 失败不扣分
- **WHEN** 图片已开始生成但因服务错误失败
- **THEN** 本轮不扣积分，失败步骤在对话流中可见
