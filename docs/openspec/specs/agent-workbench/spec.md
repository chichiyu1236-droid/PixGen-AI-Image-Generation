## Purpose

定义 Agent 对话工作台的行为契约：面向「还没有想法」的用户，用多轮对话完成图片的生成、修改与变体，全过程规划透明、积分消耗明示，并与「经典生成」表单模式在同一页面内互为对照。

## Requirements

### Requirement: 双模式入口与对照
`/generate` 页面 SHALL 同时提供「经典生成」与「Agent 对话」两种模式入口，并以用户状态对照表述（「我有大致想法」/「还没想好，聊聊看」）。Agent 对话 SHALL 为会员专属能力：非会员用户 SHALL 能看到 Agent 入口卡片，但卡片 SHALL 带会员专属锁标标识，点击后 SHALL 展示升级引导（含定价页入口）而非进入 Agent 模式。会员用户 SHALL 能在两种模式间随时切换，切换 SHALL NOT 丢失另一模式已产生的表单内容或对话/画布状态。经典模式的既有行为 SHALL 保持不变。Agent 会话与消息的服务端接口 SHALL 校验当前用户的会员状态，非会员的任何 Agent 会话请求 SHALL 被拒绝并返回明确的未授权错误码。会员期内产生的会话在会员到期后 SHALL 保留只读，MUST NOT 被删除。

#### Scenario: 首次进入默认经典模式
- **WHEN** 已登录用户访问 `/generate`
- **THEN** 页面默认展示经典生成表单，同时可见 Agent 对话模式的入口卡片

#### Scenario: 模式切换保留状态
- **WHEN** 会员用户在 Agent 模式已有对话与画布内容后切到经典模式，再切回 Agent 模式
- **THEN** 原有对话记录与画布作品保持完整，不重置

#### Scenario: 免费用户看到带锁标的入口
- **WHEN** 非会员用户访问 `/generate`
- **THEN** Agent 入口卡片可见且带会员专属锁标，页面默认仍为经典生成模式

#### Scenario: 免费用户点击入口被升级引导
- **WHEN** 非会员用户点击 Agent 入口卡片
- **THEN** 页面展示升级引导与定价页入口，MUST NOT 进入 Agent 对话模式

#### Scenario: 服务端拒绝非会员会话请求
- **WHEN** 非会员用户绕过前端直接调用 Agent 会话或消息接口
- **THEN** 系统返回明确的未授权错误码，不创建会话、不执行任何工具调用

#### Scenario: 会员到期后对话保留只读
- **WHEN** 会员期内的用户会员到期后再访问原 Agent 会话
- **THEN** 历史消息与画布作品完整展示，发起新一轮请求被拦截并提示续费

### Requirement: 会话与消息持久化
系统 SHALL 为每个用户保存 Agent 会话及其全部消息（含用户消息、Agent 回复、工具调用轨迹与产出图片引用）。用户 SHALL 只能访问自己的会话与消息；访问他人会话或消息 SHALL 得到未找到响应。

#### Scenario: 会话延续
- **WHEN** 用户离开 Agent 工作台后再次进入同一会话
- **THEN** 历史消息、工具轨迹与画布作品完整恢复

#### Scenario: 越权访问
- **WHEN** 用户请求不属于自己会话的消息或图片上下文
- **THEN** 系统返回未找到，不泄露该资源存在性

### Requirement: 对话生图
用户 SHALL 能用自然语言（含模糊、口语化表述）发起生成请求。Agent SHALL 将其转化为专业画面说明后调用生图，生成的图片 SHALL 同时出现在对话流与画布。当用户表述过于模糊时，Agent SHALL 先提出澄清问题（并提供可点选的快捷回答）再生成，MUST NOT 在关键信息缺失时直接生成无关图片。

#### Scenario: 明确请求直接生成
- **WHEN** 用户输入「做一张高端护肤品的电商海报，极简风格」
- **THEN** Agent 展示任务规划后生成图片，结果出现在对话流与画布

#### Scenario: 模糊请求先澄清
- **WHEN** 用户输入「我想发个小红书，但完全没想好要什么图」
- **THEN** Agent 提出澄清问题并提供快捷回答选项，待用户选择后再生成

### Requirement: 过程透明与工具轨迹
Agent 的每一轮执行 SHALL 在对话流中展示：规划步骤（含各步骤完成状态与耗时）、工具调用（工具名、关键入参摘要、积分消耗）。工具调用明细 SHALL 默认收起、可展开。失败的工具调用 SHALL 展示失败原因。

#### Scenario: 查看工具调用明细
- **WHEN** 用户点击对话中的工具调用卡片
- **THEN** 卡片展开显示该次调用的提示词或指令全文

#### Scenario: 工具调用失败
- **WHEN** 生图服务不可用导致工具调用失败
- **THEN** 对话流展示失败步骤与原因，本轮不扣积分，Agent 以自然语言告知用户可稍后重试

### Requirement: 多轮改图
用户 SHALL 能选中画布上的任意图片作为编辑对象，并以自然语言下达修改指令。系统 SHALL 基于选中图片执行图像编辑生成新版本，新版本 SHALL 在画布标注来源（基于哪张图哪个版本），原版本 SHALL 保留。未选中图片时用户下达修改指令，Agent SHALL 明确告知需要先选中或引导选择，MUST NOT 对错误对象执行编辑。

#### Scenario: 选中后改图
- **WHEN** 用户选中「图 1 v1」后输入「背景换成樱花色调」
- **THEN** 系统生成新图片「图 2 v2」，画布标注「基于 图 1 v1 修改」，图 1 保留

#### Scenario: 未选中时要求改图
- **WHEN** 画布有图片但用户未选中任何一张，输入「把背景换成樱花」
- **THEN** Agent 自动选中最近一张图并向用户确认编辑对象，或提示用户先选择

### Requirement: 批量变体
用户 SHALL 能对选中的画布图片发起变体生成。变体 SHALL 保持主体构图一致、按明确差异方向（如配色）生成，每个变体计为一次独立生成并单独计费。

#### Scenario: 生成两个配色变体
- **WHEN** 用户对选中图片说「给这张图生成两个不同配色的变体」
- **THEN** 画布新增两个标注「变体」的作品，均标注基于原图，共扣 2 积分

### Requirement: 积分计费与余额保护
Agent 模式下的每次图片生成与每次编辑 SHALL 各扣 1 积分（与经典模式一致），变体按个数累计。工具调用展示的积分消耗 SHALL 与实际扣减一致。余额不足时系统 SHALL 在执行前拦截并引导购买会员卡，MUST NOT 出现已扣减未产出或已产出未扣减的账实不符。

#### Scenario: 余额不足拦截
- **WHEN** 积分为 0 的用户在 Agent 模式发起生成
- **THEN** Agent 提示余额不足并给出购买会员卡入口，不调用生图工具

#### Scenario: 失败不扣分
- **WHEN** 图片已开始生成但因服务错误失败
- **THEN** 本轮不扣积分，失败步骤在对话流中可见

### Requirement: Agent 大脑适配与模拟模式
Agent 的大脑（规划用 LLM）SHALL 通过 OpenAI 兼容接口接入并可由环境变量切换提供商与模型。系统 SHALL 提供模拟大脑模式（类似计费的 mock provider 先例）：不依赖外部 LLM 即可完整走通对话、工具调用与画布交互，用于本地开发与自动化测试；生产环境未显式允许时 MUST NOT 启用模拟大脑。

#### Scenario: 模拟模式全链路
- **WHEN** 环境配置为模拟大脑且用户走完「生成→改图→变体」流程
- **THEN** 对话、工具轨迹、画布与积分扣减行为与真实模式一致

#### Scenario: 生产环境禁用模拟大脑
- **WHEN** 生产环境未显式允许模拟大脑
- **THEN** Agent 接口拒绝以模拟大脑运行

### Requirement: 图像服务健康前置检查
Agent 发起生图或改图前 SHALL 检查图像服务可用性，不可用时以自然语言告知用户并停止本轮执行，不产生积分变动。

#### Scenario: 图像服务不可用
- **WHEN** 图像中继服务返回不可用且用户发起生成
- **THEN** Agent 回复服务暂不可用提示，规划步骤标记失败，积分余额不变

### Requirement: 图片容错加载与退避重载
Agent 画布主图、缩略图、对话内出图预览（以及经典结果区与历史图库预览）SHALL 使用 `ResilientImage` 组件呈现图片加载状态与失败恢复。图片加载出错时 SHALL 按指数退避延迟自动重试（默认 `[600, 1500, 3000]` ms），对 `http:`、`https:` 与站内相对路径自动附带 `_retry` 查询参数绕过失败缓存，对 `blob:` 与 `data:` URL 保持原样不改写。自动重试耗尽后 SHALL 展示失败兜底卡片，提供「重新加载图片」手动重载按钮，以及仅面向安全 `http:`/`https:`/站内相对 URL 的「新窗口打开原图」链接；在缩略图紧凑模式（`compact`）下 SHALL 仅使用短语级元素，避免在外部 `<button>` 内嵌套交互按钮。

#### Scenario: 瞬时网络波动自动退避恢复
- **WHEN** 画布或预览图片首次加载触发 `onError`，随后存储链路恢复
- **THEN** `ResilientImage` 按默认退避间隔附带 `_retry` 参数自动重试并展示重试进度，加载成功后恢复正常预览

#### Scenario: 重试耗尽后提供手动重载与安全原图链接
- **WHEN** 图片连续加载失败达到最大重试次数
- **THEN** 组件展示「图片加载失败」兜底卡片，点击「重新加载图片」重新发起加载；当原图地址为合法 HTTP(S) 或站内相对路径时同时提供「新窗口打开原图」链接

### Requirement: 异常轮次孤儿消息清理与错误文案中文映射
`POST /api/agent/sessions/[id]/messages` 在写入用户消息后若发生大脑初始化失败、Agent 轮次执行异常或助手回复落库失败，系统 SHALL 决定是否清理已写入的用户消息并在响应体返回布尔字段 `userMessageRemoved`：
- 创建大脑失败（尚未开始工具执行）时，直接删除该条孤儿用户消息；
- 轮次执行或助手消息落库失败时，对比轮次前后的画布作品列表：确认未新增任何画布作品时删除该孤儿用户消息；若本轮已产出新作品，或轮次前/后查询画布出错无法确认是否产出新作品时，MUST 保守保留该用户消息（返回 `userMessageRemoved: false`），避免误删关联有效出图的对话记录。

前端工作台 SHALL 通过统一映射函数 `mapAgentErrorMessage` 将全部服务端错误码（如 `agent_turn_failed`、`agent_provider_unavailable`、`agent_membership_required`、`insufficient_credits`、`message_store_failed`、`session_not_found`、`not_authenticated`、`invalid_request` 等）与网络异常映射为明确中文提示，MUST NOT 向用户直接渲染原始英文错误码。

#### Scenario: 失败无出图时自动清理孤儿用户消息
- **WHEN** 用户发送消息后 Agent 轮次抛错且本轮未产生任何新画布作品
- **THEN** 服务端删除刚写入的孤儿用户消息并返回 `502 { error: "agent_turn_failed", userMessageRemoved: true }`，前端展示中文繁忙提示（明示未出图不扣积分）

#### Scenario: 已出图或画布查询异常时保守保留用户消息
- **WHEN** 轮次执行异常或助手消息落库失败，且本轮已产出新画布作品，或轮次前/后的画布列表查询返回错误
- **THEN** 服务端保留该用户消息并返回 `userMessageRemoved: false`，防止误删已有出图对应的提问记录

#### Scenario: 错误码统一中文展示
- **WHEN** Agent 接口返回已知错误码或未知英文错误码
- **THEN** 前端界面均通过 `mapAgentErrorMessage` 渲染友好中文提示，不暴露原始英文代码
